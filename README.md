📊 Power BI Sales Dashboard

📌 Project Overview

An interactive sales dashboard built using Microsoft Power BI to analyze sales performance, product revenue, customer metrics, and sales trends over time.

🎯 Project Objectives

Monitor overall sales performance.

Track total orders and customer count.

Analyze sales trends over time.

Identify top-performing products.

Compare sales across product categories.

Explore sales performance by country and date range.

📈 Dashboard Features

1. KPI Cards

A line chart showing changes in sales across years and quarters.

3. Product Performance
